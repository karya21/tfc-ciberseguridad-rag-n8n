<h1>Asistente IA de Ciberseguridad</h1>

Proyecto TFC basado en IA Generativa con RAG y n8n

El sistema permite subir documentos PDF relacionados con ciberseguridad, extraer el contenido
automáticamente y responder preguntas usando IA Generativa y RAG ( Retrieval-Augmented Generation ).

El proyecto fue desarrollado con n8n
